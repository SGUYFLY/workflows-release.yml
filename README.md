# ไทยโครงสร้าง — ระบบจัดการรับเหมาก่อสร้าง

โปรแกรมจัดการงานรับเหมาก่อสร้าง: โครงการ คลังวัสดุ ครุภัณฑ์ ร้านค้า/บริการซ่อม เอกสาร & บัญชี ทีมช่าง
แยกสิทธิ์ตามตำแหน่ง (CEO / หัวหน้างาน / ฝ่ายสโตร์ / เสมียน) และข้อมูลไม่หายเมื่อปิดโปรแกรม

มี 2 วิธีใช้ — เลือกอย่างใดอย่างหนึ่ง:

| | **A. โปรแกรม Windows** | **B. เว็บแอปออนไลน์ (ติดตั้งลงมือถือได้)** |
|---|---|---|
| เหมาะกับ | คนเดียว/สำนักงานเดียว ใช้เครื่องเดียว | ทีมหลายคน หลายเครื่อง ดูผ่านมือถือได้ |
| ต้องมีอินเทอร์เน็ต | ไม่ต้อง | ต้อง |
| เก็บข้อมูลที่ | ในเครื่องผู้ใช้ | บนเซิร์ฟเวอร์ที่คุณเช่า |

---

## A. โปรแกรม Windows (.exe)

1. ไปที่หน้า **Releases** ของโปรเจกต์นี้ แล้วดาวน์โหลด
   - `ThaiStructure-Setup-x.y.z.exe` — ตัวติดตั้งปกติ (แนะนำ) หรือ
   - `ThaiStructure-Portable-x.y.z.exe` — ไม่ต้องติดตั้ง ดับเบิลคลิกใช้ได้เลย
2. ดับเบิลคลิกไฟล์ที่ดาวน์โหลด
   - ถ้า Windows ขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC" ให้กด **More info → Run anyway**
     (ขึ้นเพราะโปรแกรมยังไม่ได้ซื้อใบรับรองลายเซ็นดิจิทัล ไม่ได้แปลว่ามีไวรัส)
3. เปิดครั้งแรกจะให้ **ตั้งชื่อ อีเมล และรหัสผ่านของผู้ดูแล (CEO)** — จำรหัสผ่านนี้ไว้ ระบบไม่มีปุ่ม "ลืมรหัสผ่าน"
4. เพิ่มพนักงานคนอื่นที่ปุ่ม **จัดการบัญชีผู้ใช้** (ซ้ายบน) โดยเลือกตำแหน่งให้แต่ละคน

**ข้อมูลอยู่ที่ไหน:** `%APPDATA%\ThaiStructure\data` (เมนู ไฟล์ → เปิดโฟลเดอร์ข้อมูล)
**สำรองข้อมูล:** เมนู ไฟล์ → สำรองข้อมูล... แล้วเก็บไฟล์ไว้ที่ปลอดภัย (กู้คืนที่ ไฟล์ → กู้คืนข้อมูล...)
**ถอนการติดตั้ง:** Settings → Apps → ThaiStructure (ข้อมูลของคุณจะไม่ถูกลบ)

## B. เว็บแอปออนไลน์

### ทางที่ 1: Render.com (ง่ายที่สุด)
1. Fork/อัปโหลดโปรเจกต์นี้ขึ้น GitHub ของคุณ
2. Render → **New → Blueprint** → เลือก repo นี้ (ไฟล์ `render.yaml` ตั้งค่าให้แล้ว)
3. เปิดลิงก์ที่ Render ให้ → ตั้งค่าบัญชี CEO ครั้งแรก → เพิ่มพนักงาน
4. **บนมือถือ:** เปิดลิงก์ในเบราว์เซอร์ → เมนู ⋮ / แชร์ → **ติดตั้งแอป / เพิ่มไปยังหน้าจอโฮม**

> ฐานข้อมูลฝังตัวต้องมี Disk ถาวร (`render.yaml` ขอไว้ 1 GB ซึ่งเป็นแผนเสียเงิน)
> ถ้าใช้แผนฟรี ให้สร้างฐานข้อมูล Postgres ฟรีที่ [Supabase](https://supabase.com) แล้วใส่ตัวแปร `DATABASE_URL` และ `JWT_SECRET` ใน Render แทน

### ทางที่ 2: Docker บนเซิร์ฟเวอร์/เครื่องตัวเอง
```
docker compose up -d
```
เปิด http://localhost:8080 — ข้อมูลเก็บใน volume `thai-data` (ควรวางหลัง HTTPS reverse proxy เมื่อเปิดให้คนภายนอกใช้)

### ทางที่ 3: รันตรงๆ ด้วย Node.js 20+
```
npm run install:all
npm run web          # build หน้าเว็บแล้วเริ่มเซิร์ฟเวอร์ที่ http://localhost:8080
```

## ตัวแปรสภาพแวดล้อม (backend)

| ตัวแปร | ความหมาย |
|---|---|
| `DATABASE_URL` | ถ้าใส่ = ใช้ Postgres ภายนอก (เช่น Supabase) · ถ้าไม่ใส่ = ใช้ฐานข้อมูลฝังตัว |
| `JWT_SECRET` | ข้อความสุ่มยาว ≥ 32 ตัว (จำเป็นเมื่อใช้ `DATABASE_URL`; โหมดฝังตัวสร้างให้เอง) |
| `DATA_DIR` | โฟลเดอร์เก็บข้อมูลของโหมดฝังตัว (ค่าเริ่มต้น `backend/data`) |
| `PORT` | พอร์ต (ค่าเริ่มต้น 4000; Docker ใช้ 8080) |
| `TRUST_PROXY` | ตั้งเป็น `1` เมื่ออยู่หลัง reverse proxy |

## สำหรับนักพัฒนา

```
npm run install:all
# เทอร์มินัล 1                     # เทอร์มินัล 2
cd backend && npm run dev          cd frontend && npm run dev      # → http://localhost:5173 (proxy ไป :8080)
```
- สร้างตัวติดตั้ง Windows บนเครื่อง Windows: `npm run desktop:dist` (ผลลัพธ์ใน `desktop/release/`)
- สร้างอัตโนมัติบน GitHub: `git tag v1.0.0 && git push origin v1.0.0` → workflow `release.yml` สร้างไฟล์ .exe แนบใน Releases
- ตรวจระบบ: `cd backend && npm run check`
- ข้อมูลตัวอย่างสำหรับสาธิต (บัญชี `@thai.local`): `cd backend && npm run seed` (ต้องใช้ `DATABASE_URL` หรือโหมดฝังตัว)
- โครงสร้าง: `frontend/` React+Vite · `backend/` Express · `desktop/` Electron · `database/schema.sql`

## ข้อจำกัดของเวอร์ชันนี้ (ควรรู้)
- โครงการและบัญชีผู้ใช้เก็บเป็นตารางจริง · โมดูลอื่น (คลัง ร้านค้า เอกสาร ทีมช่าง) เก็บเป็นก้อนข้อมูลต่อหมวด — ถ้าสองคนแก้หมวดเดียวกันพร้อมกัน ครั้งที่บันทึกทีหลังจะทับ
- ยังไม่มีพอร์ทัลลูกค้าจริง (ในโหมดสาธิตมีหน้าตัวอย่างเท่านั้น)
- ยังไม่มีระบบรีเซ็ตรหัสผ่านทางอีเมล — CEO ตั้งรหัสใหม่ให้พนักงานได้ที่ "จัดการบัญชีผู้ใช้"
- ตัวติดตั้ง Windows ยังไม่ได้เซ็นลายเซ็นดิจิทัล

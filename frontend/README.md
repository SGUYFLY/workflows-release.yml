# ไทยโครงสร้าง — ตัวต้นแบบระบบจัดการรับเหมาก่อสร้าง

ตัวต้นแบบ (prototype) แบบ interactive สร้างด้วย React + Vite ข้อมูลทั้งหมดเป็น mock data ในหน่วยความจำ (ไม่มีฐานข้อมูล/backend จริง รีเฟรชหน้าแล้วข้อมูลจะรีเซ็ตกลับค่าเริ่มต้น)

## วิธีรันบนเครื่องตัวเอง

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป

```bash
npm install
npm run dev
```

จากนั้นเปิดลิงก์ที่ terminal แสดง (ปกติคือ `http://localhost:5173`)

## โครงสร้างไฟล์

```
construction-manager/
├── index.html          จุดเริ่มต้น HTML
├── package.json         รายการ dependency (react, recharts, lucide-react)
├── vite.config.js       ตั้งค่า build tool
└── src/
    ├── main.jsx          mount React เข้า DOM
    └── App.jsx           โค้ดแอปทั้งหมด (UI + state + mock data)
```

โค้ดทั้งหมดอยู่ไฟล์เดียวคือ `src/App.jsx` เพื่อให้ง่ายต่อการดูภาพรวมและแก้ไข ถ้าจะแยกไฟล์ตามส่วน (เช่น แยก DashboardView, ProjectsView ออกเป็นไฟล์ละไฟล์) แจ้งได้ จะช่วยจัดโครงสร้างใหม่ให้

## บทบาทผู้ใช้ (สลับได้จากแถบด้านซ้ายในแอป)

| บทบาท | สิทธิ์หลัก |
|---|---|
| CEO | ดูภาพรวมทุกหน้า, อนุมัติใบเสนอราคา, อนุมัติซ่อม/จัดซื้อครุภัณฑ์ |
| หัวหน้างาน | อัปเดตสถานะโครงการ, ส่งคำขอวัสดุ, มอบหมายทีมช่าง |
| ฝ่ายสโตร์ | ปรับสต็อกวัสดุสิ้นเปลือง, จ่ายของตามคำขอ, เพิ่มคลัง |
| เสมียน | ดูแลครุภัณฑ์ (แจ้งชำรุด/ขอจัดซื้อ), เอกสาร, บัญชีรายรับ-รายจ่าย |

## จุดที่ควรตรวจสอบเพิ่มเติมก่อนใช้งานจริง (ยังเป็นข้อจำกัดของ prototype)

- **ไม่มี backend/ฐานข้อมูลจริง** — ข้อมูลอยู่ใน React state เท่านั้น ต้องต่อ API/DB จริงตาม ER Diagram ที่ออกแบบไว้
- **ไม่มีระบบ authentication** — การสลับ role ทำผ่านปุ่มเลือกตรงๆ ยังไม่มีการล็อกอิน/ยืนยันตัวตน
- **วัสดุยังไม่ผูกกับคลังแบบเต็มรูปแบบ** — แต่ละรายการวัสดุอยู่คลังเดียว ยังไม่รองรับวัสดุชนิดเดียวกันมีของอยู่หลายคลังพร้อมกัน
- **ไม่มีการรับคืนวัสดุ (stock return) แบบเต็มรูปแบบ** — ตอนนี้ปรับสต็อกด้วยปุ่ม +/- ตรงๆ ยังไม่แยกประเภทธุรกรรม (รับเข้า/เบิกจ่าย/รับคืน) ตาม ER ที่ออกแบบไว้
- **ตัวเลขและวันที่ทั้งหมดเป็นข้อมูลสมมติ** สำหรับสาธิตเท่านั้น

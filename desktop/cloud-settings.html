เชื่อมต่อข้อมูลออนไลน์ (Supabase)

กรอกค่าให้ตรงกับที่ตั้งไว้ใน Render เพื่อให้แอปเดสก์ท็อปและเว็บออนไลน์ใช้ข้อมูลและบัญชีผู้ใช้ชุดเดียวกัน

ก่อนเชื่อม: ค่า DATABASE_URL จะถูกเก็บไว้ที่โฟลเดอร์ข้อมูลของแอปในเครื่องนี้เท่านั้น (ไม่ส่งขึ้นที่ไหน) โปรดระวังอย่าแชร์ไฟล์โฟลเดอร์นั้น
คัดลอกจาก Supabase → ปุ่ม Connect → Connection string → Transaction pooler แล้วแทน [YOUR-PASSWORD] ด้วยรหัสผ่านฐานข้อมูลจริง
ต้องตรงกับค่าใน Render → Environment → JWT_SECRET เป๊ะ ๆ เพื่อให้ล็อกอินของทั้งสองฝั่งใช้ร่วมกันได้
